## 1. BioCLIP 2: What Changed

**Paper**: NeurIPS 2025 Spotlight. Stevens et al., "BioCLIP 2."

| Aspect | BioCLIP v1 | BioCLIP 2 |
|--------|-----------|-----------|
| Vision encoder | ViT-B/16 (86M params) | ViT-L/14 (~300M params) |
| Embedding dim | 512 | 768 |
| Training data | TreeOfLife-10M (10M images) | TreeOfLife-200M (214M images) |
| Base model | OpenAI CLIP ViT-B/16 | CLIP ViT-L/14 (LAION-2B pretrained) |
| Catastrophic forgetting | Not addressed | Experience replay of LAION-2B data |
| Species classification | Baseline | +18.1% over BioCLIP v1 |
| HuggingFace | `imageomics/bioclip` | `imageomics/bioclip-2` |

**Key architectural addition**: Visual projector on top of the ViT-L/14 encoder, used during all evaluation and embedding extraction.

**Embedding properties**: The 768-dim embedding space shows emergent biological structure. Intra-species variations (life stages, sexual dimorphism) are preserved in orthogonal subspaces. Species embeddings correlate with ecological and functional traits.

### Impact on SeedLearn

- All cached `.npz` files must be regenerated (512-dim incompatible with 768-dim)
- Every downstream consumer of embeddings must handle the new dimensionality
- SimpleShot centroids, distance computations, and normalization are dimension-agnostic (numpy broadcasting), so classifier code needs no changes beyond loading the new cache
- Expect meaningful accuracy improvement given the 18.1% species-level gain reported in the paper

## 2. Static Embeddings Verification

**Current cache**: Generated by BioCLIP v1 vision encoder only. No text encoder involved. Correct for v1.

**Does BioCLIP 2 have a separate embedding model?** No. The image encoder (ViT-L/14 + visual projector) IS the embedding model. Embeddings are extracted via `model.encode_image()` through OpenCLIP. There is no dedicated "embedding-only" variant.

**Action required**: Full re-extraction of all training images through BioCLIP 2's vision encoder. The existing cache is valid for v1 comparisons but cannot be reused.

**Cache regeneration scope**:
- `family_features.npz`: 8,377 images -> (8377, 768) float32
- `species_features.npz`: 8,377 images -> (8377, 768) float32
- Estimated size increase: 16MB -> ~24MB per file (1.5x from 512->768 dim)

## 3. Fine-Tuning Feasibility

### Dataset Scale

| Metric | Value |
|--------|-------|
| Total training images | 8,377 |
| Families | 49 |
| Species | 170 |
| Avg images per species | ~49 |
| Avg images per family | ~171 |

### Approach Hierarchy (ordered by risk/complexity)

**Level 0 - SimpleShot on BioCLIP 2 (no training)**
- Extract embeddings, run SimpleShot. Zero risk.
- This is the baseline everything else must beat.
- DO THIS FIRST. No exceptions.

**Level 1 - Linear Probe**
- Logistic regression on frozen BioCLIP 2 embeddings.
- Trainable params: 768 x num_classes. Negligible compute.
- Standard sklearn. No GPU needed for training.
- Good sanity check before LoRA.

**Level 2 - LoRA Fine-Tuning**
- **Proven on CLIP models.** Reference: CLIP-LoRA (Zanella & Ben Ayed, CVPR Workshop 2024).
- Apply LoRA to all weight matrices in the vision encoder (not just Q projections).
- Trainable params: ~0.1-1% of base model. Rank 4-16 typical.
- Fixed hyperparameters across tasks - no per-task tuning needed.
- Works with as few as 1-16 shots per class. Our ~49 images/species is well within range.
- No inference latency overhead (LoRA weights merge at deployment).
- **Tools**: OpenCLIP + HuggingFace PEFT, or [CLIP-LoRA](https://github.com/MaxZanella/CLIP-LoRA).
- **Compute**: Single GPU, standard SLURM allocation.

**Level 3 - ProLIP (last projection layer only)**
- Fine-tune only the final visual projection matrix with regularization.
- Distance-to-pretrained regularization prevents drift.
- Competitive with full methods on standard benchmarks.
- Simpler than LoRA, fewer moving parts.

**Level 4 - Full Fine-Tuning (NOT RECOMMENDED at this scale)**
- With 8,377 images and a 300M param model, overfitting is near-certain.
- Would require knowledge distillation + contrastive alignment (CLIP-CITE).
- Only justified at 100K+ images.

### Honest Assessment

With ~49 images per species, LoRA is the ceiling of what's responsible. Full fine-tuning would memorize the training set. The question is whether the BioCLIP 2 embeddings are already good enough that LoRA provides marginal improvement over SimpleShot. The 18.1% improvement in BioCLIP 2 may already capture most of the domain adaptation we'd get from LoRA. **We won't know until we run the Level 0 baseline.**
